# AgroLink — premium agriculture landing page

Односторінковий сайт агрокомпанії англійською мовою. Чистий HTML/CSS/JS, без збірки.

## Запуск

Найпростіше — відкрити `index.html` подвійним кліком.

Для коректної роботи шрифтів і кешу краще підняти локальний сервер:

```powershell
cd D:\Site
python -m http.server 5173
```

Далі — http://localhost:5173

## Структура

```
index.html                 розмітка всіх секцій
assets/css/base.css        токени, reset, типографіка
assets/css/components.css  прелоадер, курсор, хедер, кнопки, картки
assets/css/sections.css    розкладки секцій + медіа-запити
assets/js/preloader.js     інтро-анімація, віддає керування через подію
assets/js/main.js          Lenis, хедер, курсор, scroll-сцени
```

## Що де міняти

**Кольори** — `assets/css/base.css`, блок `:root`:

| Змінна | Роль |
|---|---|
| `--ink` / `--ink-deep` | темні поверхні, текст |
| `--canvas` / `--canvas-warm` | кремові фони |
| `--leaf` | основний зелений (кнопки, акценти) |
| `--sprout` | лаймовий акцент |
| `--brass` | охра (ціни, номери кроків) |

**Шрифти** — Fraunces (заголовки) + Manrope (текст), підключені з Google Fonts у `<head>`.

**Зображення** — прямі URL Unsplash у `index.html`. Щоб поставити свої: створіть `assets/images/`, покладіть файли туди і замініть `src`. Параметри `?q=80&w=…` в URL Unsplash керують якістю й шириною.

**Тексти** — усі всередині `index.html`, англійською.

**Товари** — блок `.cards`, шість елементів `<article class="card">`. Копіюйте один цілком, щоб додати сьомий.

**Показники** — `data-count` на `.stat__num` (число) і `data-suffix` (символ після числа). Смуги в секції Global — атрибут `data-bar` (відсоток).

## Анімації

- **Прелоадер** — GSAP timeline: поява логотипа, посимвольний вихід назви, лічильник 0→100 зі смугою, вихід шторкою вгору. Тривалість ~4.5 с.
- **Скрол** — Lenis (плавна інерція), синхронізований з GSAP ScrollTrigger.
- **Заголовки** — розбиття на рядки через SplitType, поява з-під маски.
- **Зображення** — clip-path розкриття + зняття масштабу.
- **Паралакс** — hero, фото About, фон CTA.
- **Лічильники, смуги, кроки процесу** — тригеряться при вході у в'юпорт.
- **Курсор** — кастомний, на картках товарів перетворюється на «View».
- **Кнопки** — магнітне притягання до вказівника + заливка знизу вгору.

## Доступність

- `prefers-reduced-motion` вимикає паралакс, marquee і лічильники; прелоадер скорочується до 0.3 с.
- Skip-link, видимі focus-стилі, aria-атрибути на меню й кнопках.
- Якщо CDN недоступний, сайт залишається повністю читабельним — анімації просто не вмикаються.

## Залежності (CDN)

- GSAP 3.12.5 + ScrollTrigger (cdnjs)
- Lenis 1.1.18 (jsDelivr)
- SplitType 0.3.4 (jsDelivr)
